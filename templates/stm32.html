Mission Overview

Two Autonomous Arena Challenges

How deterministic bare-metal HAL C firmware solved both precision optical navigation and rapid multi-target thermal suppression.

CHALLENGE #01 · MIDTERM

Autonomous Light Seeking & Millimeter Precision Braking

Arena: 1.0 m² enclosed perimeter with randomly positioned omnidirectional lamp targets.

While other competitors attempted complex ultrasonic or IR rangefinding arrays with unpredictable reflection latencies, Ukacha selected a lightweight dual-channel LDR (Light Dependent Resistor) differential bridge. By converting continuous lux gradients through STM32 ADC1, the robot calculated heading error in real time and modulated TIM3 PWM channels across left and right motors.

  • Optical Phototaxis: Differential light reading steers the robot toward the peak illumination vector.
  • Dynamic Stopping Threshold: STOP_THRESHOLD (3550) immediately engages counter-torque dynamic braking before physical contact with the lamp.
  • First-Attempt Success: Achieved zero collisions on the very first arena run.
CHALLENGE #02 · FINAL

360° Rotational Vortex Candle Extinguisher

Mission: Locate and extinguish 5 randomly positioned perimeter candles within a strict 30-second window.

Rather than sequential pathfinding—which wastes critical transit time driving to each individual candle—Ukacha devised an algorithmic optimization: Arena Center Homing & Rotational Vortex Sweep. The robot positions itself in the geometric center of the arena, throttles up a powerful 12V high-velocity blower fan, and executes synchronized 360-degree rotational passes.

  • Aerodynamic Blast Radius: The 12V blower fan creates an omnidirectional laminar airflow covering the entire 1 m² track perimeter.
  • Kinematic Rotation: PWM_DONME (350) differential spin produces continuous high-speed sweeps.
  • Record Benchmark: Extinguished all 5 candles in under 10 seconds—completing the task in just one-third of the allowed 30-second countdown.

/* Core Thresholds & PWM Duty Cycles */
#define PWM_NORMAL        350  
#define PWM_DONME         350 
#define PWM_ARAMA         380  
#define STOP_THRESHOLD    3550  /* Braking point before collision */
#define SEARCH_THRESHOLD  1600  /* Target detection trigger */
#define DIFF_THRESHOLD    550   /* Left/Right optical gradient */

/* TIM3 4-Channel Compare Registers */
#define SET_IN1(val) __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, (val))
#define SET_IN2(val) __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_2, (val))
#define SET_IN3(val) __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_3, (val))
#define SET_IN4(val) __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_4, (val))

/* Differential Motor Driving Functions */
static void Motor_Forward(uint16_t speedL, uint16_t speedR) {
    SET_IN1(speedL); SET_IN2(0);
    SET_IN3(speedR); SET_IN4(0);
}

static void Motor_SpinLeft(uint16_t speed) {
    SET_IN1(0);     SET_IN2(speed);
    SET_IN3(speed); SET_IN4(0);
}

static void Motor_Stop(void) {
    SET_IN1(0); SET_IN2(0);
    SET_IN3(0); SET_IN4(0);
}

/* Optical ADC Acquisition with Inverted Logic */
static uint16_t Read_LDR(uint32_t channel) {
    ADC_ChannelConfTypeDef sConfig = {0};
    sConfig.Channel = channel;
    sConfig.Rank    = 1;
    sConfig.SamplingTime = ADC_SAMPLETIME_84CYCLES;
    HAL_ADC_ConfigChannel(&hadc1, &sConfig);

    HAL_ADC_Start(&hadc1);
    HAL_ADC_PollForConversion(&hadc1, 10);
    uint16_t val = HAL_ADC_GetValue(&hadc1);
    HAL_ADC_Stop(&hadc1);

#if INVERT_LDR
    return (4095 - val);
#else
    return val;
#endif
}
