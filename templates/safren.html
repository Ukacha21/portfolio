Note on naming: Originally titled Ce-Saf (uniting Ceren + Safina), now advanced and rebranded to SafRen (uniting Safina + Ceren Başaran).

Traditional wrist-worn fitness trackers frequently suffer from false-positive step counting caused by arbitrary hand gestures, desk typing, or stationary upper-body movement. SafRen resolves this problem at the source: placing the pedometer directly inside the footwear. Powered by an ultra-compact Waveshare ESP32-S3-Zero (with Arduino Nano fallback), the system couples an MPU6050 6-DOF inertial sensor with a tactile spring ground-impact microswitch to measure true heel-strike stance vs. flight swing phases. Real-time metrics are displayed on an on-shoe 0.96" SSD1306 OLED display and streamed wirelessly over an on-chip SoftAP Wi-Fi HTTP telemetry server to a custom cross-platform Flutter companion mobile app.

ENGINEERING DEEP DIVE

Hardware Architecture & Gait Discrimination Logic

How dual-mode sensing (Inertial Acceleration + Tactile Ground Impact) eliminates false positives.

⚡

Waveshare ESP32-S3-Zero Core

Engineered around the miniature ESP32-S3-Zero footprint, delivering 240 MHz dual-core processing in a form factor no larger than a postage stamp. Its castellated solder pads allow seamless low-profile integration into shoe tongue padding or insole heel wells without burdening the wearer.

  • Clock Speed: 240 MHz Xtensa 32-bit LX7 Dual-Core.
  • I2C Bus Clock: 400 kHz fast-mode for high-frequency OLED refresh.
  • Wi-Fi Radio: 802.11 b/g/n operating in autonomous SoftAP mode.
🎯

True Gait Stance vs. Flight Phase

Unlike basic pedometers that rely solely on arbitrary acceleration spikes, SafRen implements a two-stage physical verification cycle:

  • Heel Strike (Impact): The tactile microswitch closes on heel strike, and the MPU6050 verifies a vertical dynamic G-force spike exceeding 12.0 m/s² (standard gravity = 9.8 m/s²).
  • Toe Off (Flight Phase): The system requires the foot to lift off the ground before another step can register. If the user is standing still or tapping while seated, the counter locks in standby.
  • 300ms Anti-Bounce Window: A software debouncing hysteresis prevents vibration reverberations from triggering false double-counts.
🌐

Zero-Cloud Local SoftAP HTTP Server

The device generates its own private, isolated Wi-Fi network (ESP32-Access-Point, default IP 192.168.4.1). No internet connection or cloud third-party server is required:

  • Zero Latency: Local socket-level HTTP GET streaming delivers sub-10ms response times.
  • Complete Privacy: Biometric gait and step count telemetry remains 100% on the local user device.
  • Universal Compatibility: Any web browser or the companion mobile app can read telemetry instantly.
💡

Firmware Ground Trick for Wire Reduction

To minimize the cable harness routed from the shoe sole to the microcontroller, the firmware configures a dedicated GPIO pin as an active low ground:

// Make pin 6 act as Ground to simplify routing
pinMode(BUTTON_GND_PIN, OUTPUT);
digitalWrite(BUTTON_GND_PIN, LOW);
pinMode(BUTTON_PIN, INPUT_PULLUP);

This clever embedded routing eliminated the need to run an external ground branch cable down the shoe body.

👟

Footwear Ergonomics & Optimum Spot Allocation

A critical challenge in smart footwear is placing rigid electronics without compromising natural foot kinematics, causing blisters, or damaging components under cyclic walking loads. Led by Shoe Design majors Safina Najmudinova and Ceren Başaran, the physical shoes were selected and anatomically surveyed to identify the optimum hardware spots:

  • Tongue OLED & MCU Placement: Positioned the 0.96" SSD1306 display and ESP32-S3-Zero microcontroller along the upper tongue contour, allowing glanceable viewing from above while keeping the board away from flexure creases.
  • Plantar Heel Strike Switch: Identified the precise pressure epicentre beneath the rear insole to mount the tactile ground microswitch for 100% mechanical impact fidelity without feeling foreign to the foot.
  • Anatomical Wire Seams: Routed low-gauge wiring along footwear structural stitch lines to protect interconnects from shear stresses during stride cycles.
