Deep Engineering Architecture

Convolutional Topology, Ingestion Pipeline & GUI Stack

A robust computer vision system requires more than theoretical weight matrices; it demands rigorous resolution control, reproducible image pre-processing, and accessible desktop validation tooling.

01

Resolution Normalization Engine

A fundamental principle of Convolutional Neural Networks is that input dimensionality must strictly match training specifications. Any discrepancy between training resolution (96×96) and testing images will immediately raise dimension mismatch exceptions.

  • Automated Cache: Python script creates and manages a local temps/ directory dynamically.
  • LANCZOS Resampling: Ingested images are resized preserving aspect ratio via Pillow (PIL) before tensor conversion.
  • Normalized RGB: 3-channel colour values normalized from [0, 255] to [0.0, 1.0] floating points for gradient stability.
02

Layer-by-Layer Convolutional Stack

Built using tensorflow.keras.models.Sequential(), the neural network extracts hierarchical representations through progressively downsampled spatial filter banks:

  • Conv2D (32 filters, 3×3): Receptive field captures micro-gradients and edge borders with ReLU activation.
  • MaxPooling2D (2×2): Downsamples spatial resolution by half, ensuring translation invariance against slight animal movement.
  • Conv2D (64 filters, 2×2) × 2: Deeper convolutional layers capture localized morphology (whiskers, ears, muzzle, fur textures).
03

Dual Serialized Model Weights

The repository provides two distinct pre-trained weight checkpoints in modern .keras format, demonstrating the progression of model learning:

  • 3-Epoch Baseline: cat_dog_classifier-3_epochs_x96px.keras provides a lightweight early-stage validation proof of concept.
  • 40-Epoch Converged: cat_dog_classifier-40_epochs_x96px.keras delivers deep optimization across all 9,600+ custom training samples.
  • Overfitting Mitigation: 10% validation split (seed=123) with randomized batch shuffling for robust generalization.
04

Desktop GUI & CLI Validators

Engineered for practical usability beyond command-line terminal scripts, enabling instant interactive testing on user-selected photographs:

  • Tkinter UI Validator: ui-validator.py features a native desktop file dialog, image thumbnail canvas, and real-time prediction readout.
  • OpenCV Integration: Ingestion engine utilizes cv2 and Pillow for high-performance bitmap matrix conversion.
  • Command-Line Batch: validator.py provides scriptable verification suitable for automated test suites and batch folder validation.

Production Model Architecture & Preprocessing Implementation

# Build the Deep Convolutional Neural Network
def train_model(train_data, val_data, class_names, width, height, color_channels):
    model = models.Sequential()

    # Input layer (96x96 RGB)
    model.add(layers.Input((height, width, color_channels)))
    model.add(layers.Conv2D(32, (3, 3), activation='relu'))
    model.add(layers.MaxPooling2D((2, 2)))
    model.add(layers.Conv2D(64, (2, 2), activation='relu'))
    model.add(layers.MaxPooling2D((2, 2)))
    model.add(layers.Conv2D(64, (2, 2), activation='relu'))

    # Flatten the 2D feature map into a 1D representation
    model.add(layers.Flatten())

    # Fully connected dense layers
    model.add(layers.Dense(64, activation='relu'))
    model.add(layers.Dense(len(class_names), activation='softmax'))

    model.compile(
        optimizer='adam',
        loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=False),
        metrics=['accuracy']
    )
    return model

# Dynamic Resolution Normalization & Testing Buffer
def prepare_test_image(path, img_width=96, img_height=96):
    try:
        os.mkdir('temps')
    except FileExistsError:
        pass

    image = PILImage.open(path)
    resized_image = image.resize((img_width, img_height))
    temp_path = "temps/adjusted.jpg"
    resized_image.save(temp_path)
    return temp_path
